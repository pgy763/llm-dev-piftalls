# 401 有两种：key 错了，和钱没了

## 报错

**第一种：key 错**

```
openai.AuthenticationError: Error code: 401 -
{'error': {'message': 'Incorrect API key provided: sk-abc***xyz. You can find your API key at ...',
           'type': 'invalid_request_error', 'code': 'invalid_api_key'}}
```

**第二种：额度用完**

```
openai.APIStatusError: Error code: 401 -
{'error': {'message': 'You exceeded your current quota, please check your plan and billing details.',
           'type': 'insufficient_quota', 'code': 'insufficient_quota'}}
```

有时是 **429** 而不是 401 —— 同一件事，不同服务商给的状态码不一样。

## 现象

监控上只看到「401 比例上升」，值班的人第一反应是「key 被人改了」，查半天发现是**账户余额归零**。

## 为什么

两种情况的 HTTP 状态码几乎一样，含义完全不同：

| `code` | 含义 | 该谁处理 |
| --- | --- | --- |
| `invalid_api_key` | key 不对、被删、环境变量没读到 | 开发 |
| `insufficient_quota` | 余额/额度用尽、账单未付 | 运营/财务 |
| `billing_not_active` | 账户未激活或欠费 | 运营 |

而 `429` 又是第三种：**请求太快**，等一会儿就好，跟钱无关。

**三者混在一起的代价**：告警发给了错的人，恢复时间被拉长。

## 怎么改

### 一、按 `error.code` 分流，别只看状态码

```java
catch (APIStatusError e) {
    String code = e.body() == null ? "" :
            String.valueOf(e.body().get("code"));     // 或自己解析 JSON

    switch (code) {
        case "insufficient_quota", "billing_not_active" ->
            alert("配额耗尽", e);          // 发给运营，不是开发
        case "invalid_api_key", "invalid_organization" ->
            alert("凭据失效", e);          // 发给开发
        default -> {
            if (e.statusCode() == 429) backoff();  // 限流：退避重试
            else throw e;
        }
    }
}
```

### 二、启动时做一次探活，把 401 提前

```java
@PostConstruct
void probe() {
    try {
        client.models().list();          // 最小调用
    } catch (APIStatusError e) {
        throw new IllegalStateException("模型服务不可用：" + e.statusCode() + " " + e.getMessage(), e);
    }
}
```

启动失败比运行中静默降级好 —— 至少 K8s 不会把流量打进来。

### 三、把 401/429 拆成三条监控曲线

```
auth_invalid_key_total     ← 配置问题，应该长期为 0
auth_quota_exhausted_total ← 业务指标，可预测（按 token 消耗推算）
rate_limited_total         ← 容量问题，看是否需要提额或排队
```

## 怎么预防

- 余额监控：按日均 token 消耗算「还能撑几天」，少于 7 天就提醒
- 每个环境用独立的 key 和独立账户，别让测试环境把生产额度吃掉
- 报错里**必须带上 `error.code` 原文**，只记 `401` 等于没记

## 环境

| 组件 | 版本 |
| --- | --- |
| 调用方 | Spring AI 1.0 / LangChain4j / 官方 SDK |
| 触发条件 | key 失效、余额归零、账户欠费 |
| 相关异常 | `AuthenticationError`、`APIStatusError`、`RateLimitError` |
